# Security policy

## Scope

This repository publishes third-party engine files to a static site. In scope:

- The workflow publishing anything other than the release named in `assets.lock`
- The workflow skipping the checksum check
- A way to make the published site serve altered files

Out of scope: vulnerabilities in BusyTeX or TeX Live themselves, which belong with those projects,
and anything in Vitafolio, which has [its own policy](https://github.com/zaccesss/vitafolio/security/policy).

## Reporting

Use [private vulnerability reporting](https://github.com/zaccesss/vitafolio-latex/security/advisories/new).
Please do not open a public issue.

The full policy is at [zaccesss/security-policy](https://github.com/zaccesss/security-policy) and
[isaacadjei.me/security-policy](https://isaacadjei.me/security-policy). This file takes precedence
where the two differ.
